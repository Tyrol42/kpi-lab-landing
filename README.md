# Лендинг «Продвижение сайтов поведенческими факторами» для KPI LAB

Проект выполнен в рамках тестового задания: разработка конверсионного одностраничного лендинга в фирменном стиле агентства **KPI LAB**, реализация модуля сквозной аналитики источников трафика (UTM-метки, органика Яндекса/Google, рекламные клик-идентификаторы) и безопасная передача лидов в Telegram.

---

## 📌 Ключевые возможности и особенности реализации

1. **Дизайн и фирменный стиль KPI LAB**:
   - Палитра: акцентный синий `#005FAB`, мягкий фон `#fafbfe`, современная контрастная типографика.
   - 100% адаптивная верстка (Mobile First) под смартфоны (iPhone, Android), планшеты и мониторы высокой четкости.
   - Информативная структура: Hero-экран с динамикой трафика (+340%), механика влияния ПФ на алгоритмы поисковиков, этапы вывода в ТОП-3, продающая форма с триггерами доверия.

2. **Модуль трекинга источников (`tracker.js`)**:
   - Парсинг всех стандартных UTM-меток: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`.
   - Распознавание системных клик-идентификаторов рекламы: `yclid` (Яндекс Директ), `gclid` (Google Ads).
   - Интеллектуальное распознавание органических переходов по `document.referrer`:
     - `yandex.ru` / `ya.ru` $\rightarrow$ **Органический поиск Яндекса (SEO)**
     - `google.com` $\rightarrow$ **Органический поиск Google (SEO)**
     - Отсутствие меток и реферера $\rightarrow$ **Прямой заход (Direct)**
   - **Сохранение в `sessionStorage`**: при обновлении страницы или серфинге по сайту исходный источник первого визита не теряется.

3. **Форма обратной связи и валидация (`form.js`)**:
   - Автоматическая маска ввода номера телефона `+7 (___) ___-__-__`.
   - Защита от пустых или некорректных данных: проверка длины имени, полноты номера телефона, согласия с политикой обработки данных.
   - Асинхронная AJAX-отправка (без перезагрузки страницы), спиннер на кнопке, защита от двойных кликов, уведомление об успехе.

4. **Безопасность передачи данных (Backend & Telegram API)**:
   - **Токен бота и Chat ID строго изолированы на сервере** в файле `.env` и никогда не попадают в браузер клиента.
   - Поддерживает два варианта развертывания:
     - Обычный Node.js/Express сервер (`server.js`) — для локальной работы или VPS/Render.
     - Serverless API (`api/lead.js`) — для моментального бесплатного хостинга на **Vercel** без выделенного сервера.
   - Встроенный **Mock-режим**: если токен в `.env` не заполнен, сервер корректно зафиксирует заявку, выведет форматированный лог в консоль и вернет клиенту успешный статус.

5. **Инспектор аналитики (виджет в правом нижнем углу)**:
   - Специальный интерактивный виджет для тестирования: прямо на странице показывает, какой источник определил трекер, какие UTM-метки распознаны, и содержит кнопки быстрого запуска сценариев проверки.

## 🛠 Быстрый старт и локальный запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка Telegram-бота
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и укажите данные вашего бота:
```env
PORT=3000
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
```

> **Как получить токен и ID чата за 1 минуту:**
> 1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`, укажите имя и получите `TELEGRAM_BOT_TOKEN`.
> 2. Нажмите `START` в диалоге с созданным ботом.
> 3. Откройте бота [@userinfobot](https://t.me/userinfobot), он пришлет ваш цифровой `Id` — это `TELEGRAM_CHAT_ID`.

*(Если оставить переменные пустыми, система запустится в Mock-режиме и будет выводить оформленные сообщения в терминал).*

### 3. Запуск сервера
```bash
npm start
```
Лендинг будет доступен по адресу: **http://localhost:3000**

## 🧪 Сценарии для проверки (согласно ТЗ)

### Сценарий 1: UTM-переход (Рекламная ссылка Яндекс Директ)
1. Откройте в браузере размеченную ссылку:
   ```
   http://localhost:3000/?utm_source=yandex&utm_medium=cpc&utm_campaign=pf_promo&utm_content=banner_top&utm_term=prodvizhenie_pf
   ```
2. Заполните форму: Имя, Телефон, Сайт.
3. Нажмите «Получить расчёт и аудит».
4. **Результат в Telegram:**
   ```
   🔥 НОВАЯ ЗАЯВКА С ЛЕНДИНГА KPI LAB
   ───────────────
   👤 Имя: Иван
   📞 Телефон: +7 (999) 123-45-67
   🌐 Сайт/Проект: site.ru

   📊 Источник перехода:
   Яндекс Директ (Контекстная реклама)

   🏷 UTM-метки:
   • utm_source: yandex
   • utm_medium: cpc
   • utm_campaign: pf_promo
   • utm_content: banner_top
   • utm_term: prodvizhenie_pf

   🔗 Реферер: Прямой заход (без реферера)
   📱 Устройство: Десктоп (ПК)
   ⏰ Время заявки: 17.09.2026, 18:40:00 (МСК)
   ```

### Сценарий 2: Переход без меток (Прямой заход или Органика)
1. Откройте чистый адрес: `http://localhost:3000/`
2. Заполните форму и отправьте.
3. **Результат в Telegram:**
   - Источник: `Прямой заход (Direct)` (или поисковик, если переход был из поиска);
   - `UTM-метки: отсутствуют`.

### Сценарий 3: Валидация формы
1. Попробуйте нажать кнопку «Получить расчёт и аудит» с пустыми полями:
   - Форма не отправляется.
   - Поля подсвечиваются красным контуром с поясняющими сообщениями («Введите имя», «Укажите полный номер телефона»).
2. Введите 3 цифры телефона: форма сообщит о неполном номере.

## ☁️ Развертывание в интернете (Vercel)

Проект полностью оптимизирован для мгновенного бесплатного деплоя на [Vercel](https://vercel.com):
1. Сделайте `git push` в репозиторий GitHub.
2. В панели Vercel нажмите **Add New Project** $\rightarrow$ выберите данный репозиторий.
3. В разделе **Environment Variables** укажите:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Нажмите **Deploy**. Проект сразу получит рабочий HTTPS-адрес с функционирующим серверным API `/api/lead`.
